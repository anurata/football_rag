# Jリーグ リアルタイム試合速報 & 動的分析スキル (`live-match-tracker`)

このスキルは、進行中のJリーグ公式戦（明治安田J1/J2等）の多層データソース（Yahoo!実況・確定スタッツ、SPAIA個人スタッツ、Xサポーター感情）を統合し、
動的な勝率予測や戦術交代カードの提示、試合終了時の完全スタッツ総括を行うための標準手順書です。

※試合前のプレビュー共同作成や、試合後の詳細な戦術総括キュレーションについては、統合共同作成スキル `match-curator` を参照してください。

詳細なシステム仕様書: `docs/live_match_tracker_spec.md`

---

## 1. 発動トリガー (When to Use)

- 「速報を更新して」「今のスコア・状況は？」「試合どうなってる？」
- 「動的勝率を再計算して」「交代カードの予測を更新して」
- 「ハーフタイムの分析をして」「前半どうだった？」
- 「試合が終わったので試合終了速報をまとめて」「確定スタッツを出して」

---

## 2. 実行コマンドと手順 (Execution Procedure)

### 基本実行（直近の戦況と予測レポートをMarkdownで出力）
```bash
python scripts/live_match_forecaster.py
```

### 次の試合や任意の試合ID・クラブハッシュタグを指定する場合
```bash
python scripts/live_match_forecaster.py --game-id <YAHOO_GAME_ID> --hashtag "#fctokyo"
```

### JSONデータとして取得する場合（外部連携用）
```bash
python scripts/live_match_forecaster.py --game-id <YAHOO_GAME_ID> --json
```

## 3. レポート構成と出力フォーマット

1. **⏱️ 現在の戦況**:
   - スコア（ホーム vs アウェイ）、経過時間（前半○分 / 後半○分 / HT / 試合終了）、得点者・時間
2. **⚡ 直近のピッチ速報・ログ (Yahoo! データスタジアム)**:
   - 最新のシュート、CK、オフサイド、警告、得点、交代などの直近4〜5件
3. **🔥 ピッチ上のキーマン個人スタッツ (SPAIA公式リアルタイム集計)**:
   - 注目選手のパス成功率、敵陣パス率、シュート、クリア数、タックル数、走行距離
4. **💬 X(Twitter) サポーターのリアルタイム反響**:
   - ハッシュタグに基づく現地・視聴サポーターのリアルな声（3〜4件厳選）
5. **📊 リアルタイム勝率 (Live Bayesian Win Probability)**:
   - ホーム勝利 / 引き分け / アウェイ勝利 の最新パーセンテージ、残り時間の期待ゴール (xG)
6. **🔄 戦術交代・アジャスト予測**:
   - 各チームの点差・時間帯に応じた推奨カード、投入意図、緊急度

---

## 4. 厳格運用ポリシー（ハルシネーション防止の3大鉄則）

1. **【事実（Fact）】と【推測（Inference）】の完全分離**:
   - 一次データに明記されていないディテール（パスの軌道、プレスの状況、トラップの有無など）は断定しない。
   - 推測を述べる場合は必ず `【※状況推測】` を付与する。
2. **情緒的修飾語の排除（ドライ・ファクトモード）**:
   - 「神がかった」「ズバッと」「冷静に流し込み」などの未観測な形容詞・副詞を禁止する。
3. **ユーザーへの過剰迎合の禁止**:
   - ユーザーの興奮した発言に同調して、未確定の状況を創作・脚色しない。
