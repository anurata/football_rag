# J1戦術分析・観戦ガイドRAG システム仕様書
## 試合前プレビュー＆試合後レビュー キュレーション仕様書 (Curation Service Specification)

---

### 1. 概要・設計原則

本仕様書は、試合前の展望レポート（プレビュー）および試合後の戦術総括レポート（レビュー）を共同作成・自動生成する **キュレーションサービス群** の機能仕様を定義するものです。
『理念憲章（TACTICAL_PHILOSOPHY_AND_MANIFESTO.md）』に則り、以下の3大原則を厳格に順守します。

1. **【事実】と【推測】の完全分離**:
   - ピッチ上の動かぬ記録（Layer 1: スコア、出場時間、スタッツ）には `【事実】` タグを付与。
   - 戦術的因果や将来展望（Layer 4〜6: プラン意図、勝敗予想）には `【推測】` タグを明記し、境界線を曖昧にしない。
2. **3案分岐シナリオの提示 (Tri-Scenario Branching)**:
   - 単一の決めつけ予測を排除し、「プランA（本命・正攻法）」「プランB（対抗・迎撃型）」「プランC（大穴・リスクテイク型）」の3案を根拠データ付きで提示。
3. **結果バイアスの排除 (Elimination of Outcome Bias)**:
   - スコアラインの勝敗に引きずられず、「プロセスの成否（内容）」と「結果（スコア）」を分離して因果を解剖。

### 2. 試合前プレビューキュレーション仕様 (`PreviewCurationService`)

- **実装クラス**: `pipeline.preview_curation_service.PreviewCurationService`
- **主要入力**: `data/football.db`, `data/structured/fctokyo_season_tactical_synthesis.json`
- **出力形式**: Markdown形式プレビューレポート（`exports/{match_id}_preview.md`）

#### 2.1 確定事実の自動抽出 (Fact Extraction)
- **基本情報**: 節、日時、会場、天候、過去の直接対決通算成績（勝・分・敗）。
- **直近フォーム**: 両チームの直近5試合の勝敗、平均得失点、平均xG。
- **相手戦術アーキタイプ**: `fctokyo_cross_analytics` による相手守備タイプ判定（ハイプレス / ミドルブロック / ローブロック）。
- **スカッド状況**: 負傷離脱者、累積警告、前節先発メンバー、キープレイヤー。

#### 2.2 3案分岐シナリオの推論ロジック

| シナリオ | 戦術プラン設計 | 相手アーキタイプに応じた推奨根拠 |
| :--- | :--- | :--- |
| **プランA（王道・主導権掌握）** | 自信のある基本布陣（4-2-3-1）でのビルドアップと位置的優位の追求。 | 相手がローブロックの場合、両翼アイソレーションとハーフスペース侵入でこじ開ける。 |
| **プランB（迎撃・カウンター）** | あえて保持を譲り、中盤に網を張って即時奪回から縦に速く刺すBPI重視プラン。 | 相手がハイプレス型の場合、相手背後の広大なスペースを突くロングカウンターが極めて有効。 |
| **プランC（奇襲・可変システム）** | 3バック可変や前線のハイタワー投入による空中戦・セットプレー特化プラン。 | 相手の守備ブロック弾力性が極めて高い場合の打開策。 |

### 3. 試合後レビュー・戦術カルテ仕様 (`ReviewCurationService`)

- **実装クラス**: `pipeline.review_curation_service.ReviewCurationService`
- **出力形式**: 確定戦術カルテ（`exports/J1_2026_全節戦術カルテ.md`）

#### 3.1 内容と結果の因果判定マトリクス

| 試合内容（プロセス） | 最終結果（スコア） | 判定カテゴリ | 戦術総括の論理構造 |
| :---: | :---: | :---: | :--- |
| **優勢** (xPTS $\ge 2.0$) | **勝利** (3pts) | **【必然の勝利】** | 戦術プロセスが機能し、実力通りにスコアを結実させた理想的ゲーム。 |
| **互角/劣勢** (xPTS $< 1.5$) | **勝利** (3pts) | **【運勝ち・守護神】** | 内容的には苦戦したが、個の決定力やGKのファインセーブで勝ち点を拾った試合。 |
| **優勢** (xPTS $\ge 2.0$) | **敗戦/分** (0-1pt) | **【構造的惜敗】** | チャンス構築は機能したが、フィニッシュの不運や相手GKの超人的セーブに阻まれたゲーム。 |
| **劣勢** (xPTS $< 1.0$) | **敗戦** (0pt) | **【完敗・力負け】** | 相手の戦術プランに完封され、構造的な修正が急務となるゲーム。 |

#### 3.2 構成セクション
1. **試合概要と確定スタッツ**: スコア、得失点者、xG比率、Field Tilt、走行量。
2. **【事実】ピッチ上で起きた動かぬ記録**: 得点時間、警告、主要交代の事実ログ。
3. **【推測】勝敗を分けた戦術的因果**: プレス強度の噛み合わせ、選手交代による潮目の変化。
4. **選手個別パフォーマンス評価**: トップCreator（PageRank）、デュエル勝率、MOM。
5. **次節への課題と提言**: 疲労度（ACWR）と相手アーキタイプへの適応課題。
